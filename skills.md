# NITI — guide for AI agents

This is a reference for helping users understand NITI, not an installable skill or a connection to their tasks.

## Find information

1. Read the [product summary](https://ext7.github.io/niti-daily-task-planner/llms.txt).
2. Use the [site map](https://ext7.github.io/niti-daily-task-planner/sitemap.md) to find public pages.
3. Verify features in the [website](https://ext7.github.io/niti-daily-task-planner/) and [release notes](https://ext7.github.io/niti-daily-task-planner/updates/).

## Help a user get started

Direct the user to the Chrome Web Store link on the homepage. The [welcome page](https://ext7.github.io/niti-daily-task-planner/welcome/) explains how to pin and open the extension. Core task planning works offline without an account.

## Explain privacy and limitations

Use the [privacy policy](https://ext7.github.io/niti-daily-task-planner/privacy-policy/) for data-handling questions. Tasks and projects are stored in the browser; do not claim automatic cloud synchronization. Public pages and these reference files do not grant access to user tasks or expose an API or MCP endpoint. Do not ask for passwords, browser profiles or private backups to explain the product.

## Follow public updates

The [RSS feed](https://ext7.github.io/niti-daily-task-planner/rss.xml) is maintained manually for public website resources. It is not a task event stream or a complete product release history; use the release notes for product changes.
